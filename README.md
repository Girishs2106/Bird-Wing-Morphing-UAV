
# Bird Wing Morphing UAV – Mechanical Design

## Project Overview
A mechanical engineering project focused on developing a bird-inspired morphing wing aircraft model.

## Work Involved
- Bird-inspired wing mechanism design
- 3D CAD modelling using SolidWorks
- Wing geometry and structural design
- Motion studies
- Aerodynamic analysis
